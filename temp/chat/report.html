📋 Quick Deliverables Checklist

  • Deliverable 1: Working Application & Source Code – Full repository structured with SOLID principles & Dark/Light theme.
  • Deliverable 2: Video Explanation – Structured talking points and on-camera script covering the 3 most important decisions.
  • Deliverable 3: What You Chose Not to Implement – 3 features with clear rationales:
    • Auth/JWT: Omitted to avoid superficial localStorage tokens vulnerable to XSS; true production auth requires httpOnly cookies, refresh-token rotation, and RBAC.
    • Cloud Storage Attachments: Kept the data model lean without Base64 BSON bloat or requiring evaluators to configure AWS S3 billing credentials.
    • WebSockets: Avoided stateful server cluster overhead (Redis Pub/Sub); reactive React hooks and optimistic UI already deliver instant sync.
  • Deliverable 4: Implementation Limitation – Lack of server pagination with 1-day extension roadmap:
    • Current Limitation: Full dataset fetching creates ~3.5MB JSON payload and $O(N)$ DOM node memory bloat for large datasets (10,000+ tasks).
    • 1-Day Solution: Add MongoDB $facet cursor pagination, compound indexing, 300ms search debounce, and client-side virtualized list windowing.
